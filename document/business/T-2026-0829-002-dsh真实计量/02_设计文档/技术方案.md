## How(关键实现)

**1. 会话定位(F1)**
- 快路径:候选目录名 = `--` + workdir 字符串将 `:`/`\`/`/` 等非字母数字转 `-` + `--`,驱动器字母大小写两个变体都试(实证:同机存在 `--D-...` 与 `--d-...` 两种)。
- 兜底:遍历 sessions_dir 下所有 `*/session.jsonl.zstd`,读**首帧** session 头 JSON 的 `cwd` 字段,与 workdir 归一化(大小写/斜杠)比较。
- 多候选取"最后一条记录 time 最大"者;无候选 → None。

**2. 解析(F2/F3)**
- `zstandard.ZstdDecompressor().stream_reader(BytesIO(raw)).read()` 全帧读取(实证:`decompress()` 只读首帧,1MB 文件只出 199 字符)。
- 逐行 `json.loads`(坏行跳过);命中 `type=="assistant/chunk"` 且 `data.chunk.type=="usage"` 且 `e["time"] >= since_ms`;按 `(data.turn, data.step)` 去重取末条;汇总 `inputTokens/outputTokens/cacheReadTokens`(缺键按 0)。
- 无任何命中 → None(=会话源不可用)。
- 整个解析 try 包裹,任何异常 → None(F6:不炸 run)。

**3. 成本(F4/F7)**
- `rates` 配置:`{"deepseek": {"input_per_m": 2.0, "cache_hit_per_m": 0.5, "output_per_m": 8.0}, "glm": {"input_per_m": 0, "cache_hit_per_m": 0, "output_per_m": 0}}`。
- cost = input×input_per_m/1e6 + cache_read×cache_hit_per_m/1e6 + output×output_per_m/1e6,round 4 位。
- provider 键:packet.model 命中 rates 用之,否则 "deepseek"。
- tokens 归一 {"input_tokens","output_tokens"}(cacheRead 只进 cost,不进 tokens——水位虚高教训)。

**4. 优先级链(F5,集成进 dsh.run)**
- run 开始记 `run_start_ms = time.time()*1000`(减 5s 时钟缓冲)。
- trailer 解析成功 → 精确值(现状,estimated=False)。
- 否则尝试会话解析(含 timeout 分支:已完成的 step 也有 usage):
  - 命中 → `tokens/cost_cny=真实值, estimated=False, usage_missing=False`(有账,不标缺失);status 仍按 returncode/timeout。
  - 未命中(双缺)→ **恢复硬契约**(boss 决):`status="failed", usage_missing=True, cost_cny=est_call_cny, estimated=est>0`——判负但照估禁记 0(R9),两约并立。
- 影响:T-004 的"无 trailer 按 returncode 推进"被本链取代;test_dsh_adapter 三例降级断言改写为双缺判负断言(mingfang 闸 warn-only 不受影响,那是 runner 层)。

**5. 配置与依赖**
- orchestrator.yaml 加 `rates:` 段(注释:官网标准价 2026-08,改价改配置)。
- cli.py:`rates=cfg.get("rates")` 透传 get_adapter → DshAdapter(rates=..., sessions_dir 默认 `~/.dsh/sessions`,测试可注入)。
- requirements.txt +`zstandard`(注释:装包先配镜像,运维教训)。
