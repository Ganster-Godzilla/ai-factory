# 功能清单 —— Dashboard v2

| # | 功能 | 优先级 | 验收标准 |
|---|---|---|---|
| F1 | 工单中心列表页 `/tickets` | P0 | 默认 id 倒序全量;列:工单号/项目/状态/负责人/优先级/摘要;行点击进详情 |
| F2 | 工单中心筛选:项目+状态 | P0 | GET 参数 `project`/`state`,可组合;非法值忽略并回默认 |
| F3 | 工单中心关键词搜索 | P0 | GET 参数 `q`,大小写不敏感匹配 id+summary |
| F4 | 工单中心排序 | P1 | GET 参数 `sort`(id asc/desc、按文件 mtime 近似"最近更新");表头可点切换 |
| F5 | 项目中心泳道图 `/projects` | P0 | 行=项目;列=P0提案/P1需求/P2设计/P3执行/P4验证/P5发布/监控/挂起;chip=工单号+摘要截断,点击进详情;closed/done 不展示 |
| F6 | 泳道图→工单中心联动 | P1 | 项目名点击跳 `/tickets?project=<name>` |
| F7 | 总览:事件摘要工单号链接化 | P0 | `<a href="/ticket/<id>">` |
| F8 | 总览:待审批卡片点击跳审批中心 | P1 | 整卡可点 |
| F9 | 总览:项目状态迷你条 | P0 | 每项目一格:运行中/待审批/挂起计数,口径与审批中心一致(排除 suspended 组计入待审批);点击跳 `/tickets?project=<name>` |
| F10 | 导航栏扩展 | P0 | 总览/工单中心/项目中心/审批中心,active 态正确 |
| F11 | 单测覆盖 | P0 | 新增装配函数(ticket 列表过滤/搜索/排序、泳道分组、项目迷你条计数)纯函数单测;路由级冒烟 |
